The rules allow external data if it is "freely & publicly available to all — pretrained models included."

Some widely used academic medical-imaging datasets (for example the Stanford AIMI releases) are free for anyone to access, but access is through a standard research-use agreement whose terms include non-commercial-use and no-derivative-works clauses.

Two questions, so we can plan within the rules:

1. Does a dataset behind such a free-but-signed research-use agreement count as "freely & publicly available to all" for this competition?
2. If a winning solution used a model pretrained on such a dataset, would that conflict with the winners' open-sourcing obligation as the hosts read it?

A written answer either way would be appreciated — happy to simply not use such data if the answer is no.
